Ghromex 引擎

本地浏览器

一个只浏览本地文件的迷你浏览器：工具条固定在顶部，换页后依然存在。

在顶部地址栏输入本地 HTML 路径（相对路径以当前页面所在目录为基准，也支持 file:// 绝对路径），点「打开」即可；或直接点击下面的卡片。 外部链接与缺失文件都会显示提示页，工具条与导航按钮照常可用。

试试边界行为

  • 外部样式表：样式写在 .css 文件里，靠 <link> 与 @import 加载
  • 外部链接：本示例不联网，改为显示提示页（工具条保留）
  • 不存在的页面：显示错误页，可用顶部「后退」返回
